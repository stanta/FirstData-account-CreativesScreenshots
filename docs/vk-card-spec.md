# ВК: карточка v2 — компактная шапка и креатив без полей

**Дата:** 21.10.2026. **Основание:** эталон VK и уточнение Максима Б.  
**Статус:** реализовано в ветке `fix/vk-card-spacing-stretch-20261021`.  
Карточка — визуальный макет, **не свидетельство опубликованной рекламы**.

## Поля и Telegram flow

| Место карточки | Источник | Параметр |
| --- | --- | --- |
| Центральный креатив | PNG/JPEG пользователя | `creative` |
| Логотип в круге | отдельный PNG/JPEG пользователя | `vk_logo` |
| Заголовок в шапке | текст пользователя | `vk_header_text` |
| Текст под кнопкой, включая абзацы | текст пользователя | `vk_body_text` |
| Подпись кнопки | версия каталога CTA | `vk_cta_id` |
| Возраст «Реклама · N+» | явный ввод, 0..99 | `minimum_age` |

Единственный согласованный CTA — «Подробнее». URL, UTM, favicon и названия сообщества в данном VK-flow отсутствуют.

Старт → ВК → «Карточка с кнопкой — 1080×607» **или** «Карточка с кнопкой — 600×600» → креатив → логотип → заголовок → основной текст → CTA → возраст → предпросмотр → адресное редактирование/подтверждение → PNG-документ.

«◀ Назад» и «Отмена» доступны при заполнении. Редактирование увеличивает revision, аннулирует прежний PNG. Для подтверждения одновременно проверяются revision, SHA-256 и версия профиля предпросмотра, затем отправляется **тот же файл**, без повторного рендера. Ошибка отправки допускает повторную попытку; после успешного завершения, отмены либо 30 минут бездействия файлы удаляются.

## Согласованная геометрия

Ширина исходного DOM-контейнера на снимке DevTools: **551,02 CSS px**. Пользователь подтвердил **16 CSS px суммарно** (две области по 8) между *содержимым шапки* и *креативом*.

На готовом PNG шириной 1080 px: `round(16 * 1080 / 551.02) = 31 px`.

Нижняя граница содержимого шапки — `header_content_bottom = 121` (нижняя граница круга логотипа в системе half-open coordinates). **Креатив начинается на y=152**, интервал 31 px уже входит в высоту шапки. Нельзя прибавлять его повторно.

| Область | Широкая 1080×607 | Квадратная 600×600 |
| --- | --- | --- |
| Шапка вместе с зазором | y=0..151 | y=0..151 |
| Основной креатив | x=0..1079, y=152..758 | x=0..1079, y=152..1231 |
| Кнопка | x=0..1079, y=759..847 | x=0..1079, y=1232..1320 |
| Основной текст | y≥848 | y≥1321 |
| Минимальная итоговая высота | 1081 px | 1554 px |

**Между изображением и CTA ровно 0 px.** Их области имеют одну границу. Под изображение нельзя дополнительно подкладывать белые полосы.

Исходник неверных пропорций **независимо масштабируется по обеим осям** для заполнения всего слота (`Pillow.Image.resize((slot.width, slot.height), LANCZOS)`). Нет обрезания или добавляемых полей; пропорции самого изображения при необходимости искажаются. Существующие белые участки *внутри исходного файла* не удаляются. Исходный креатив не перезаписывается. Правила масштабирования логотипа остаются пропорциональными.

Высота кнопки (89 px), нижний текст с переносами и сохранением пустых строк, DejaVu Sans, ограничение высоты PNG 4096 px, контроль длины заголовка и алгоритм цвета CTA не изменены. Автоматический цвет CTA — воспроизводимая аппроксимация, не подтверждённый алгоритм ВК.

## Версионированные ресурсы

- `docs/design/vk/card-v2.svg`, `docs/design/vk/card-square-v2.svg` — исходники оформления.
- `reports_ad/data/masks/VK/card-v2.png` — маска широкой версии (1080×848): первые 152 строки шапки непрозрачны, креатив и CTA прозрачны.
- `reports_ad/data/masks/VK/layout-v2.json` — профиль 1080×607.
- `reports_ad/data/masks/VK/layout-square-v2.json` — профиль квадратного слота 1080×1080 (рекомендуемый пользовательский файл 600×600).
- `reports_ad/data/masks/VK/cta-options-v1.json` — неизменённый согласованный CTA-каталог.
- `reports_ad/vk_card.py` — рендер и валидация.
- `reports_ad/vk_flow.py` — FSM, контроль версии и контрольной суммы предпросмотра.

Квадратный вариант применяет тот же `card-v2.png`: рендерер оставляет шапку, увеличивает прозрачную область и переносит нижний прозрачный фрагмент к новой высоте CTA без изменения элементов интерфейса. Исходные v1-файлы остаются доступными для отката, но активный VK-рендер использует v2.

## Тестирование

```bash
python -m compileall -q reports_ad tests
python -m pytest -q tests/test_vk_card_rendering.py tests/test_vk_card_v2.py tests/test_vk_bot_flow.py
python -m pytest -q tests/test_validation.py tests/test_composition.py
python -m pytest -q -m "not telegram_e2e and not network" tests
```

Проверка wheel включает `card-v2.png` и два JSON-профиля. E2E Telegram с отдельным тестовым ботом:
`TELEGRAM_E2E=1 python -m pytest -q -m telegram_e2e tests/e2e/test_vk_card_flow.py`.

Проверять визуально на одинаковых исходниках обе версии карточки, а не сравнивать изображения с разным содержимым. Полная идентичность с опубликованной рекламой ВК не подтверждается одним примером.
